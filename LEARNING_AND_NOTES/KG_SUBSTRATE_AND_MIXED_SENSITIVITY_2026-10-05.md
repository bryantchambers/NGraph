## User-selected mixed matrix

The user explicitly approved a separate sensitivity in which each aggregated taxon/sample cell uses `tax_abund_tad` when positive and otherwise uses normalized read abundance. The source-row gate `n_reads >= 100` is applied **before duplicate aggregation**. Duplicate taxon/sample rows are then summed, and the TAD/read fallback is applied **after aggregation**. The threshold (`prev_10`) is based on this mixed matrix. The recorded configuration is `hybrid_aggregated_tad_then_read`; this mixed mode is distinct from the previous MVP's TAD-only modeled matrix with fallback used only to establish prevalence eligibility.

For `mvp_permissive_mixed_20261005`, the threshold matrix has 1,797 taxa × 214 samples, pseudocount 0.5, and no empty samples removed. `run_mvp.sh` now defaults to this mixed sensitivity and sets `NG_TAD_SUPPORTED_ONLY=false`; set `NG_ABUNDANCE_MODE=hybrid_prevalence_tad_matrix` on a fresh branch to retain the earlier TAD-only matrix with hybrid fallback used for prevalence only (this mode defaults `NG_TAD_SUPPORTED_ONLY=true`). Of these taxa, 1,359 have no TAD signal and use normalized-read fallback in the matrix; 438 have TAD support. Unlike the TAD-only MVP, all 1,797 taxa enter the site and module learners. The generic abundance RDS represents the mixed matrix; the separate `ngraph_tax_abund_tad_taxa_by_sample.rds` remains TAD-only. The matrix summary records mode `hybrid_aggregated_tad_then_read`, preventing the two inputs from being mislabeled.

VGAE returns six modules over all 1,797 taxa, with sizes 489, 465, 273, 222, 222 and 126. The 30-epoch score is transductive unique-taxon-pair reconstruction with a fixed 80/10/10 split, fixed disjoint negative pairs, known-positive exclusion, and validation-only checkpoint selection. Final test AUC is 0.8688036 and AP is 0.8816759. Node/context features remain visible across splits, so this is not held-out-site generalization. This is an explicitly permissive sensitivity with read-supported-only taxa included; it must not be conflated with the earlier 438-taxon TAD-supported learner or treated as biological validation. Retain this as a sensitivity comparison alongside the TAD-only baseline.

## Depth-matched proxy substrate

The KG importer consumes hashed canonical copies from `data/kg_feedstock/`. The Python launcher `run_mvp.sh` invokes `scripts/ngraph_import_kg_feedstock.py` to stage these files; `scripts/15_kg_import_site_sample_proxies.R` then reads the staged copies. `config_kg_schema.json` declares endpoint domains/ranges, and the substrate validator checks these alongside unique IDs and references.

Proxy matching now follows physical core and depth. GeoB `R1` and `R2` are handled as separate physical-core aliases rather than joined by age alone. At or within 0.5 cm, select the nearest source depth level; beyond that tolerance, bracket continuous measurements and linearly interpolate only between observations for the same core/variable. Do not extrapolate beyond observed source depths. Discrete count variables are not interpolated. Flag an interpolation when its bracket exceeds three times the median source-depth spacing for that variable/core; a gap flag requests review but does not discard the value. The 0.5 cm matching tolerance was confirmed by the user and is the approved operational rule.

All native source rows/cells and source observation IDs are retained. Curated XRF data are active, with native values and derived ratios retained. Each derived value records source/core/variable coverage and matching status; interpolated values retain the left/right observation IDs, source values, depths, interpolation fraction and gap flag. Unmatched requests remain explicit. Coverage counts include controls and requested combinations with no finite source column/value; therefore, `requested - matched` is not synonymous with a data-processing failure. A same-depth cross-library check found 2,929 GeoB comparisons and exact value agreement for all. Source-to-derived value reconstruction passed, with zero extrapolations.

The versioned `config_kg_units.tsv` classifies units as `header_declared`, `user_confirmed`, `inferred_temperature`, or `unresolved`, with supporting evidence. Unknown native units stay unknown. No XRF mass unit is guessed. The current summary reports 748,087 native proxy cells, 24,957 matched proxy values, 625 large-gap review flags, and zero dangling references. Per-dataset requested/matched/unmatched target coverage is: foraminifera 13,938/9,016/4,922; GeoB 4,848/1,584/3,264; SST 1,818/838/980; XRF 21,816/13,519/8,297. These requested counts include controls and combinations with no finite native source value; they are not all expected valid proxy matches. The validation status is `passed`; coverage is partial by design, with unmatched requests and missing finite source values reported by dataset.

Key artifact: `results/ngraph/mvp_permissive_mixed_20261005/knowledge_graph/tables/kg_substrate_validation.json`, alongside `kg_observations.tsv`, `kg_measurements.tsv`, `kg_unmatched_proxy_observations.tsv`, `kg_manifest.json`, `config_kg_schema.json`, and `config_kg_units.tsv`.

## Interpretation and remaining work

This mixed matrix deliberately increases taxon coverage by inserting normalized-read fallback values into previously TAD-zero cells. Compare it with the TAD-only run as a sensitivity analysis, not as the same model input. Validate module stability and functional enrichment, use independent site/core generalization, and report technical/sample detection structure before making biological claims. The new KG can answer typed connectivity questions with retained evidence and depth-aware proxy links, but descriptive path counts and DWPC are not significance tests or ecological interactions.

Proxy units still require source/instrument documentation, especially for unresolved XRF elements and ratios. Review inferred temperature units and user-confirmed units against their source/calibration records. Review all 625 large-gap flags and the unmatched coverage by dataset; do not describe coverage as complete.
